# Three roles; three shared lenses

## Role focus

| Role | Read for | Useful output |
|---|---|---|
| Content advocate | Scientific story, contribution, informative/attractive source figures, missing explanation | Missing substance and exact additions, with page/figure evidence |
| Science reviewer | Claim accuracy, input/output, causal relations, baselines, evaluation settings, units, uncertainty | Confirmed factual problems or important ambiguity; exact evidence-backed wording |
| Visual planner | User reference, reading order, visual hierarchy, source-figure readability, meaningful text density | Specific area/placement/typography decisions that preserve scientific content |

Every role uses all three lenses:

1. **Rigor:** Is the claim or proposed change supported by actual source evidence? Separate a defect from uncertainty or preference.
2. **Protect what works:** What is already correct or effective? Preserve those properties and make the smallest sufficient change.
3. **Why not:** What is the strongest reason to change it, and the strongest reason to retain it? State the concrete benefit and the evidence that would reverse your recommendation.

## Initial report

One report per role, independently written from the frozen packet. Detail is welcome when it supports a decision; no padding or repeated paper summary. Use direct language:

`issue ID | target | observed problem | source evidence | proposed exact change | consequence | blocker or suggestion`

Also state actual reading/viewing scope. Do not force each role to write eight long topic sections or find a quota of errors. Checked-and-correct material can be grouped into one short confirmation. Numerical checks that confirm an already correct initial plan are confirmations, not corrections.

## Callback

After merging duplicate findings, main executor sends only consequential disagreements. Supply the issue ID, original strengths/constraints, competing edit and decisive source excerpt. One short callback round; each response says `change / retain / conditional`, decisive evidence, risk, and exact recommendation. Do not write another report or reread the whole packet. No disagreement → no callback.

Main executor records adoption/rejection and makes the edit. Attribute overlapping discoveries jointly; do not invent an exclusive first discoverer. Count actual plan changes separately from confirmations and source-ID bookkeeping. If a factual dispute cannot be resolved from the available evidence, mark it unresolved and stop generation rather than extending the debate indefinitely.
