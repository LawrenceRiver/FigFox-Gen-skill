# FigFox-Gen V3: SVG-grounded scientific figure generation

## Scope and execution
FigFox-Gen converts a scientific Methodology into one generated scientific figure, PNG1. The calling agent executes the skill through its available tools. This is an orchestrated workflow, not a newly trained neural model, an autonomous multi-agent service, or a claim of guaranteed scientific correctness. Editable SVG reconstruction is a separate optional user-invoked FigFox workflow and is outside this diagram. The explicit research-poster branch is outside this default figure-generation overview.

## Method input and scientific content
Read the Methodology and optional user requirements first. The Methodology determines exact scientific components, labels, dependencies, assumptions and innovation depth. Optional reference images are subject to the active SVG-only source requirement. References inform drawing constructions rather than supplying unsupported scientific modules. The scientific graph remains independent of stylistic choices.

## SVG evidence and settled narrative
Inspect genuine vector SVG figures from about two relevant scholarly papers when available. Record actual topology, input/output objects and useful intermediate representations; filter each observed construction against the current Methodology. Preserve stable visual-need identifiers, map needs to observed constructions and settle the exact visible content. Retrieve only for unmet needs, reuse valid inspected local sources and report SVG gaps. Cross-track replacements are partial construction evidence, not substitutes for missing same-track architecture details.
Collect complete frame, typography, line and arrow grammar from a genuine SVG. Separately retain one complete SVG from another track for colour relationships: original paint values, compatible neighbours, strong colours separated by whitespace, emphasis and covered area. Retain source URLs, hashes and relevant original CSS. Locally rendered PNGs are viewing/transport derivatives of retained SVGs; raster images wrapped in SVG are rejected. Fixed palette-library runs remain historical replay paths rather than the default.
Contexts 1, 2 and 3 record relevant conventions, exact scientific content/relationships, and an essential-only visual kit with the source palette. These records and the visual-need correspondence form the Creative Director input. Evidence gathering may overlap where independent; no separate agent ensemble is implied.

## Creative Director
One actual Creative Director reasoning pass integrates the Methodology, settled narrative, useful complete SVG constructions and the dedicated palette source. It decides a final source-derived palette with justified tints or tones, region colours, adjacency/separation and whitespace. It then jointly places content-sized frames and routes before filling them with exact text, supported notation and meaningful local visuals. Most ordinary frames have one input and one output; source-supported exceptions preserve scientific dependencies. The Director produces three brief design intentions, a topology review, concrete construction ideas, an exact visible-text/symbol inventory and the generation plan. White surfaces, dark type and restrained meaningful colour dominate. Titles receive no automatic colour strips. Do not force equal cards or a filled rectangular silhouette.

## Compile and preflight
The deterministic compiler checks source SVGs and hashes, source-derived colour decisions, correspondence coverage, component/edge identity, notation and geometry. Active plans use simple straight routes or one necessary smooth quadratic/cubic curve, with explicit ports. Staircase/maze routing triggers frame regrouping before generation. Checks reject missing decisions or malformed artifacts, not prove visual correctness. A compact image prompt preserves scientific invariants, scoped attachments, selected colours, exact components/routes and the Director's construction decisions. The full research remains in provenance files.

## One generation and inspection
Make one image-generation call using the compact packet and its actual permitted attachments. Deliver PNG1 and inspect the rendered pixels for scientific topology, arrow landings, containment, readable labels, whitespace and colour use. Keep the Methodology, evidence, Director brief, plan, prompt and known deviations. Deterministic artifact validation remains distinct from scientific and visual inspection. No automatic extra repair generation or editable-SVG conversion is part of this default workflow.
